# CV Website — Implementation Plan

**Date:** 2026-08-11 · **Owner:** Dinh Van Tien · **Source:** `cv-source/Hopee_Dinh Van Tien.docx.md`

## Goal
Professional CV/portfolio site. Beautiful, senior-engineer credibility, demonstrates technical skill. Ship to GitHub + Vercel prod in one pass.

## Stack
| Concern | Choice | Why |
| --- | --- | --- |
| Framework | Next.js 15 App Router | Vercel-native, zero-config deploy |
| Language | TypeScript strict | Typed content layer prevents CV data drift |
| Styling | Tailwind CSS v4 (`@theme` tokens) | No config file, CSS-first tokens |
| Fonts | `next/font/google` Inter + JetBrains Mono | Self-hosted, zero layout shift, variable |
| Motion | IntersectionObserver + CSS transitions | No animation lib dep (YAGNI); ~0kb |
| Icons | Inline SVG (Lucide paths) | No emoji-as-icon; no icon lib dep |
| Rendering | Static (RSC, no client data) | Fast, cheap, no runtime deps |

Rejected: framer-motion (bundle cost for scroll reveal only), shadcn/ui (few components needed), MDX (content is structured data, not prose).

## Design system
Derived from `ui-ux-pro-max`: Dark Mode (OLED) + Minimalism + Motion-Driven; Developer-Tool color family.

- Canvas `#08090C`, panel `#0F1218`, panel-hi `#151A22`, edge `#1E2530`
- Foreground `#F1F5F9`, muted `#94A3B8`, dim `#64748B`
- Accent `#5B9CFF` (single accent, disciplined), live-status `#34D399`
- Mono used for dates, labels, metadata — signals technical register
- Token names avoid Tailwind collisions (`bg-canvas` not `bg-base`; `text-base` is a font-size utility)

## Section order (storytelling-driven)
1. **Header** — sticky, scroll-spy nav, Download CV
2. **Hero** — name, role triad, positioning line, 4 stat tiles, CTAs
3. **About** — expanded personal summary, role/domain facts
4. **Skills** — 8 categorized groups w/ emphasis tiers (primary vs working)
5. **Experience** — 12-project timeline, expandable detail panels, role/team/duration/tech
6. **Platforms** — 6 shipped platforms + store-release credibility
7. **Education & Languages** — PLACEHOLDER
8. **Contact** — PLACEHOLDER links
9. **Footer**

## Content model
`src/content/` typed modules — single source of truth, imported by sections.
- `types.ts` — `Project`, `SkillGroup`, `Platform`
- `profile.ts` — name, roles, summary, stats, contact (placeholders flagged)
- `skills.ts` — 8 groups from CV skill inventory
- `platforms.ts` — 6 platforms
- `projects/` — split by era to keep files <200 lines: `projects-2025-current.ts`, `projects-2023-2025.ts`, `projects-2022-2023.ts`, `index.ts`

## Data decisions
- **12 projects** documented in CV; CV claims "15+ projects" → stat reads 15+, timeline shows the 12 detailed ones.
- **Years:** CV says "3+ years" but timeline runs 2022/03 → now = ~4yr5mo. Site says **4+ years**. Flagged for owner review; revert in `profile.ts` if intentional.
- **Placeholders** (CV has no data): email, phone, GitHub, LinkedIn, location, education, JLPT level, portrait. Marked `isPlaceholder` so they render visibly as TODO, not as fake data.
- Kept CV's overlapping dates as-is (Check-in App + Hotel PMS both 2023/08–2025/12; Delivery Game 2025/12–Current).

## Deploy

3. `gh repo create tien-hopee/my-profile --public`, push `main`

5. Verify live URL returns 200 + screenshot
